# MoneyRoad

Готовый многостраничный сайт MoneyRoad с интерактивным калькулятором выплат.
Проект подготовлен как статический экспорт: после сборки его можно разместить на
обычном виртуальном хостинге, GitHub Pages, Netlify или Vercel.

## Стек

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- статический экспорт без серверного backend

## Требования

- Node.js 20.9 или новее (рекомендуется Node.js 22 LTS)
- npm 10 или новее

## Локальный запуск

```bash
npm ci
npm run dev
```

Откройте адрес `http://localhost:3000`.

## Проверка и сборка

Полная проверка:

```bash
npm run check
```

Только production-сборка:

```bash
npm run build
```

Готовый статический сайт создаётся в папке:

```text
out/
```

Для проверки уже собранной папки:

```bash
npm run start
```

## Публикация на обычном хостинге (Timeweb и аналоги)

1. Выполнить `npm ci`.
2. Выполнить `npm run build`.
3. Загрузить **содержимое** папки `out/` в корневую папку сайта, обычно
   `public_html/`.
4. Подключить домен `mrmoneyroad.ru`.
5. Выпустить бесплатный SSL-сертификат Let’s Encrypt.

Node.js на хостинге не нужен: сервер получает уже готовые HTML, CSS, JavaScript,
изображения и видео.

## Публикация на GitHub Pages

В проекте есть workflow `.github/workflows/deploy-pages.yml`.

1. Загрузить проект в репозиторий GitHub с основной веткой `main`.
2. Открыть **Settings → Pages**.
3. В **Build and deployment → Source** выбрать **GitHub Actions**.
4. Workflow автоматически соберёт и опубликует папку `out/`.
5. Файл `public/CNAME` содержит домен `mrmoneyroad.ru`.

Если используется другой домен, измените `public/CNAME` и
`NEXT_PUBLIC_SITE_URL`.

## Публикация на Vercel

1. Импортировать GitHub-репозиторий в Vercel.
2. Framework Preset: **Next.js**.
3. Build Command: `npm run build`.
4. Output Directory: `out`.
5. Нажать **Deploy**, затем добавить домен в настройках проекта.

Настройки также продублированы в `vercel.json`.

## Публикация на Netlify

1. Импортировать GitHub-репозиторий в Netlify.
2. Build command: `npm run build`.
3. Publish directory: `out`.
4. Добавить домен в **Domain management**.

Настройки также продублированы в `netlify.toml`.

## Переменные окружения

Секретных API-ключей нет.

Доступна одна необязательная публичная переменная:

| Переменная | Назначение | Значение по умолчанию |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Основной адрес для SEO, sitemap и robots.txt | `https://mrmoneyroad.ru` |

Пример находится в `.env.example`. Если переменная не задана, сайт использует
домен `https://mrmoneyroad.ru`.

## Backend, данные и внешние сервисы

- backend отсутствует;
- база данных отсутствует;
- авторизация отсутствует;
- формы с отправкой данных отсутствуют;
- персональные и банковские данные не собираются;
- результаты калькулятора работают только в браузере и не сохраняются;
- внешние API не используются;
- переходы в Telegram являются обычными внешними ссылками;
- перед переходом к администратору результат калькулятора копируется в буфер
  обмена браузера.

## Логика калькулятора

- младше 14 лет: предложения не показываются;
- 14–17 лет: доступны только подходящие дебетовые карты;
- 18 лет и старше: доступны все категории;
- дебетовая карта исключается, если пользователь уже был клиентом этого банка;
- накопительный счёт и бизнес-пакет не исключаются из-за наличия дебетовой карты;
- бизнес-пакет выбирается только целиком;
- заёмные предложения доступны только совершеннолетним после подтверждения
  понимания обязательств;
- первые 1–3 заёмных предложения считаются по 1 000 ₽;
- последующие считаются минимум по 500 ₽, поэтому результат выводится с
  формулировкой «от».
